Esta tienda utiliza la misma arquitectura que EntregaManiobras. La actualización incorpora temas completos, premenú, promociones con horario y plantillas, fondos configurables y administración desde la propia tienda.

Primero actualiza el backend compartido siguiendo las [instrucciones de EntregaManiobras](https://github.com/KrispinBAM21/EntregaManiobras/blob/codex/diseno-promociones-comida-20261005/platform/DISENO-COMIDA.md). Ejecuta promotions-update.sql una sola vez y actualiza saas-platform. Luego integra esta propuesta y espera GitHub Pages. No necesitas duplicar tablas ni crear otra función para VentaComida.

Se conserva la configuración de este repositorio y su identificador venta-comida. Cada negocio guarda su propio diseño y promociones. Los módulos del bot siguen condicionados a la suscripción del propietario.
